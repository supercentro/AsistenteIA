# Privilege inventory (machine-derived from app/)

Assumptions proved later against a live database (task 5.4):
- ORM INSERT lists only the columns passed to the constructor and returns the primary key and the server-generated columns (SELECT on them).
- A Core insert(Model) executed with a list of rows may return the primary key (INSERT ... RETURNING pk), observed in the spike (H4); it needs SELECT on the key.
- An ORM attribute assignment flushes UPDATE <t> SET <attrs> WHERE <pk> (SELECT on the key).
- SELECT ... FOR UPDATE needs the UPDATE privilege on at least one column of the locked table.
- session.get(Model, id) and select(Model) read every mapped column.
